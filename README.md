# AprovaLab

Copiloto de estudos para o **vestibular** — dados reais de aprovação + IA para dizer ao aluno
**onde ele está, o que estudar e como evoluir** até o curso dos sonhos.

> Produto em **planejamento**. Documentação em [`/docs`](docs/README.md).

## Ideia em uma frase
O aluno escolhe o curso e a universidade que quer. O sistema mostra a meta real (nota de corte,
concorrência, pesos), aplica um **simulado diagnóstico** baseado no histórico de provas, e a IA
gera um **plano de estudos personalizado** — repetido de tempos em tempos para medir a evolução
e replanejar. Com gamificação (flashcards, XP, streak).

## Stack
Angular (PWA) · Supabase (Postgres, Auth, RLS, Storage, Edge Functions) · API do Claude (no
servidor). Ver [`docs/ARCHITECTURE.md`](docs/ARCHITECTURE.md).
